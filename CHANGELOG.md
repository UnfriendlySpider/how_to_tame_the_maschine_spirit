# Changelog

One section per GitHub release, newest first. `tools/release.py <tag>`
takes the section under `## <tag>` as the release notes; the rest of the
heading becomes the release title. A release carries the paper and the
deck, `PAP_ML19.pdf` and `PRE_ML19.pptx`; one staged with `--full` also
carries `PRE_ML19-full.pptx`, the deck with its drawings at full resolution.
The first release carries the paper alone.
